# Security

Please report suspected vulnerabilities privately. Do not include exploit
details, credentials, or private code in public issues or pull requests.

Use the repository's **Security → Report a vulnerability** option:

https://github.com/asnunes/farol/security/advisories/new

Include the affected Farol version, operating system, reproduction steps,
and potential impact. Use a minimal example with synthetic data.

Farol is in alpha. Security fixes target the latest release; older versions
do not have a separate maintenance policy.
