# Contributing to Farol

Farol is in alpha. Bug reports, documentation improvements, and focused
pull requests are welcome.

## Get started

Follow the [development guide](docs/development.md) to install the toolchain
and build the project. See [AGENTS.md](AGENTS.md) for code conventions.

## Propose a change

For bugs, open an issue with reproduction steps, expected and actual behavior,
and your Farol version and operating system. Remove credentials and private
code from examples.

For a larger change, open an issue to discuss the approach before implementing it.

## Submit a pull request

Keep the change focused and write code, comments, and documentation in English.
Add or update tests when behavior changes, and run:

```bash
just check
```

Explain the problem and what your change does. Screenshots help for UI changes.

For security vulnerabilities, follow [SECURITY.md](SECURITY.md).
